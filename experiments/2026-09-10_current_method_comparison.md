# 当前方法完整对比表（2026-09-10）

本表直接读取已完成的 preference-only 正式长训练及后续部署诊断汇总文件。此版三种指令共用相同硬约束，仅改变奖励偏好。旧版 SC、CC、MAPPO 结果使用不同环境设置，不纳入本表排名。

正式训练：IC_HAPPO 与 HAPPO_hidden_instruction，各 3 个训练种子（85、218、966），每个模型 10,000,000 环境步，共 6 个模型、60,000,000 环境步。另有 3 种无需训练的规则方法。

评估：每个模型/规则均使用相同的 13 个场景 × 20 个评估种子（20261701–20261720）× 600 时隙；正式评估共 2,340 个 episode、1,404,000 时隙。

表中 RL 数值为 3 个训练种子评估均值的均值 ± 样本标准差；规则没有训练种子标准差，故只列均值。标准差不是置信区间。综合奖励越高越好（负数也如此），仅在相同任务或相同场景组合内比较。AoI 单位为时隙，越低越好；PSNR 是固定平均质量表给出的已交付块预测均值，不代表连续视频端到端实测质量。更新数为每时隙成功交付数；资源用量为每时隙复信道使用次数，不能脱离交付量和质量单独排名。

## 方法定义

| 方法 | 实际做法 |
|---|---|
| 带指令 RL | HAPPO 策略可见指令与需求，学习资源分配和模式选择。 |
| 隐藏指令 RL | 从训练开始屏蔽 actor 的显式指令及需求输入；critic 可见任务。当前环境保证配对固定策略的物理轨迹不因指令变化而改变。 |
| 单一固定规则 | 始终采用模式 5、平均分配资源。 |
| 按指令选档规则 | 均衡/质量采用模式 5、平均分配；AoI 采用模式 0、按缓存 AoI 总和分配资源。规则由此前校准冻结。 |
| 单步贪心规则 | 根据当前指令，在 3 种模式 × 3 种资源分配候选中比较精确下一时隙奖励；使用当前全局状态及环境模型，不使用未来信息。 |

单步贪心规则的全局状态和一步模型使用条件不同于分散执行 RL，论文需交代这一点。

## 可以得出的判断

1. 当前带指令 RL 的总体奖励高于隐藏指令 RL 与单一固定规则，低于按指令选档规则与单步贪心规则；四个方向均在三个训练种子中一致。
2. 指令响应清楚：带指令 RL 在 AoI 指令下 AoI 约 2.503、PSNR 约 25.358 dB；质量指令下 AoI 约 3.486、PSNR 约 29.908 dB。隐藏指令 RL 在配对指令场景下物理指标完全相同。
3. 带指令 RL 并非每个任务都输给选档规则：固定 AoI 任务的奖励更高；固定质量任务是清楚的落后项。
4. 质量指令下，将同一 RL 模型的资源分配替换为平均分配后，奖励从 0.117603 升到 0.125304，接近选档规则的 0.125311；只替换模式后为 0.117596。支持质量任务的主要差距在资源分配这一部署组件。
5. 平均分配在 AoI 和均衡任务下会降低奖励；总体仅 1/3 种子改善，不能据此直接把所有任务统一改成平均分配。
